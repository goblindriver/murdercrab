# Celia upstream provenance

This directory is a vendored copy of **Celia**, a PICO-8 TAS framework built on
picolove (a LÖVE-based PICO-8 reimplementation).

- **Upstream:** https://github.com/gonengazit/Celia
- **Vendored at commit:** `7559eec68b461e7048493cfe11aa9aec8d15af76`
  ("Merge remote-tracking branch 'picolove/master'")
- **Upstream README:** preserved as `README-celia-upstream.md`
- **Upstream license:** see `LICENCE.md`

## Our modifications

We keep changes to upstream files as small as possible so future upstream pulls
stay manageable. Current diff against vendored commit:

| File | Change |
|------|--------|
| `api.lua` | +4 lines near line 1699: `pcall(require "murdercrab_bootstrap")` + `bootstrap.pre_init()` call immediately before `pico8.cart._init()`. Hook injection point only — all logic lives in `murdercrab_bootstrap.lua`. |
| `.gitignore` | +1 comment documenting that `carts/murdercrab.p8` is a build artifact (generated by `run.sh`) and intentionally stays matched by the `*.p8` rule. |
| `carts/murdercrab.p8` | **Generated** by `run.sh` via `cp pico8/murdercrab.p8 carts/`. Not tracked. LÖVE's `love.filesystem` sandbox won't resolve a symlink whose target is outside the project directory, so a copy is required. Canonical cart remains `pico8/murdercrab.p8`. |

Files we added (not upstream):

- `murdercrab_bootstrap.lua` — host-side boot hook. Currently seeds the RNG via
  `api.srand(SEED)` before the cart's `_init` runs. Future phases (host-side
  bot, debug HUD) will extend this file.
- `run.sh` — convenience launcher.
- `UPSTREAM.md` (this file).
- `README.md` — Murdercrab-specific usage notes. (Upstream README is
  `README-celia-upstream.md`.)

## Pulling upstream changes

```
git clone https://github.com/gonengazit/Celia /tmp/celia-upstream
diff -ru /tmp/celia-upstream tools/celia
```

Apply upstream changes manually to the files we touched (`api.lua`), leaving
our insertion block intact. Update the commit SHA above when done.

## Why vendor instead of submodule

- Celia upstream is low-activity; manual pulls are rare.
- Our modifications are surgical and inspectable; colocated history is easier
  to reason about than a submodule pointer.
- The whole vendored tree is ~800KB, which is not worth a submodule's overhead.
