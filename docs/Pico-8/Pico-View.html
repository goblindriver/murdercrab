2023

In 2023, we ran a monthly zine all year for PICO-8. We had articles covering art, music, sound effects, programming, and game design. Each issue also includes a list of the best games that came out that month, and a featured in-depth game review. Each month also featured a large 128x128 full screen pixel art, and a pixel art gallery spotlighting a different pixel artist.
