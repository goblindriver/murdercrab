## Commit priorities

2. `assets/svg/`
3. `assets/png_16x/` and `assets/png_64x/`
4. `assets/backgrounds/`
5. `assets/hud/`
6. `assets/diagrams/`
7. `docs/asset_manifest.json`

## Best usage
- **SVG**: manuals, print, vector layout, clean scaling
- **PNG 16x / 64x**: social, decks, web, quick comps
- **GIFs**: devlogs, repo previews, itch page snippets
- **Background plates**: poster backdrops, menu mockups, page spreads
- **HUD assets**: manual spreads, UI docs, press kits
- **Diagrams**: operator manual, design docs, tuning briefs
