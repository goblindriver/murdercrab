# MurderCrab Media Asset Extraction Pack

This pack was generated from the current PICO-8 cart in `murdercrab-main.zip`.

## Included
- exact spritesheet rebuilt from `__gfx__`
- isolated exact pixel-vector SVGs
- 16x nearest-neighbor PNG exports
- GIFs only for animations that are explicit in code

## Accuracy note
These exports are exact to the current cart art for the referenced sprites/composites. No speculative boss animation GIFs were created.
